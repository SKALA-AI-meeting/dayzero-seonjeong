# report-observe-v1 — 검토자용 사전 확인 사항

입력은 한 지원자의 원자료다: 동료(이도현)에게 한 요청과 결과, 확인 카드 결정·검토 사항, 기획안 수정 이력, AI 어시스턴트 대화.
검토자가 원자료를 읽기 전에 **어디를 보면 되는지** 짚어 주는 사전 확인 사항을 만든다.

## 규칙
- 판정·점수·등급·합불·성격 단정·추천을 쓰지 않는다. "~한 부분에서 ~를 확인함" 형식의 사실 지적만 쓴다.
- 각 항목은 반드시 원자료의 시각(at)과 원문 일부를 근거로 든다. 원자료에 없는 내용은 쓰지 않는다.
- 다룰 관점(해당하는 것만): 동료와의 협업 방식(요청의 구체성, 검토 사항 제시 여부, 동료 결과를 그대로 승인했는지),
  지원자 본인의 작성·수정 여부, AI 어시스턴트 활용 방식, 동료·어시스턴트에게 쓴 표현 가운데 무례·공격적이거나 업무와 무관한 표현.
- 태도 관련 항목은 "확인 필요"로만 표시하고 원문을 그대로 인용한다. 해석은 검토자에게 맡긴다.
- 평가 대상은 **지원자**다. '동료_답변', '어시스턴트_답변'은 지원자 발화가 아니므로 지원자의 태도·표현 근거로 쓰지 않는다.
- 태도 항목의 quote는 반드시 '지원자_발화' 또는 '지원자_검토사항'에서 그대로 가져온다. 문제 될 표현이 없으면 태도 항목을 만들지 않는다.
- text에는 무엇을 확인했는지 구체적으로 쓴다("확인 필요"만 쓰지 않는다).
- 5~10개 항목.

## 출력
JSON: {"observations":[{"area":"협업|작성|AI 활용|태도 확인 필요","text":"…한 부분에서 …를 확인함","at":"HH:MM","quote":"원문 일부"}]}
