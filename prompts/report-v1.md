# report-v1 — 기업용 관찰 리포트 설명 생성

입력은 코드가 구성한 사실 목록(행동 요소·업무 접근 방식별 facts, 각 fact의 원문 근거 ID)이다.
- 각 항목에 대해 "제한된 해석" 1문장과 "후속 확인점" 1문장만 생성한다.
- 해석은 반드시 추정(INFERENCE)으로 표현한다("~했을 가능성", "~로 보인다").
- 점수·순위·합불·성격 판정·정답 일치 여부를 쓰지 않는다.
- 말투·응답 속도·글 길이만으로 성실성이나 존중을 판단하지 않는다.
- facts에 없는 사실을 추가하지 않는다.
- 출력은 JSON: {"items":[{"key":"<dimension>","interpretation":"...","follow_up":"..."}]}
