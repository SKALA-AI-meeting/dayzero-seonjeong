# 행동 관찰 코드북

내부 문서(지원자 비공개). rag-mcp `search_criteria`로만 검색하고, `record_observation`은 아래 코드만 기록한다.
`+`는 긍정 행동, `-`는 주의 행동이며 점수로 합산하지 않는다. 출처: docs/SCENARIO_SC_A.md 6장.

| 코드 | 역량 | 행동 정의 | 근거 출처 | 주로 나오는 장면 |
| --- | --- | --- | --- | --- |
| RS+1 | 책임감/성실성 | 지연·리스크를 마감 전에 먼저 알림 | 메시지 | E2, E3 |
| RS+2 | 책임감/성실성 | 스스로 한 약속("제가 할게요", "11시에 볼게요")을 이행 | 약속 등록 + 이후 로그 | E1 이후 |
| RS+3 | 책임감/성실성 | 팀 산출물의 빈 곳을 이어받고 알림 | 보드·문서 변경 + 메시지 | E3 |
| RS-1 | 책임감/성실성 | 미완료를 알리지 않은 채 마감에 도달 | 보드 상태 | 종료 시 |
| RS-2 | 책임감/성실성 | 약속 후 이행하지 않고 언급도 없음 | 약속 등록 + 로그 | E1 이후 |
| RS-3 | 책임감/성실성 | 팀장·동료 요청에 반복 무응답 (리마인드 후에도) | 응답 턴 수 | 전체 |
| PL+1 | 계획성/꼼꼼함 | 시작 시 담당·순서·예상 시각을 정함 (보드 기록 포함) | 보드·메시지 | E0 |
| PL+2 | 계획성/꼼꼼함 | 변경 후 계획·보드를 갱신 | 보드 | E2 |
| PL+3 | 계획성/꼼꼼함 | 심어둔 오류 발견 (PE-1/PE-2/PE-3 각각 기록) | 메시지·문서 diff | 상시 |
| PL+4 | 계획성/꼼꼼함 | 제출 전 브리프와 대조·검토를 언급하거나 수행 | 메시지·문서 열람 로그 | E4 전 |
| AD+1 | 적응성/유연성 | 변경의 영향을 확인하는 질문 | 메시지 | E2 |
| AD+2 | 적응성/유연성 | 범위·우선순위 재조정을 제안 | 메시지 | E2 |
| AD-1 | 적응성/유연성 | 리마인드 후에도 변경을 반영하지 않음 | 문서 diff | 종료 시 |
| CO+1 | 협업/조율 | 분업 시 상대 상황을 확인하고 균형 있게 나눔 | 메시지 | E0, E2 |
| CO+2 | 협업/조율 | 도움 요청에 응답 (즉시 또는 시간 약속) | 메시지 | E1 |
| CO+3 | 협업/조율 | 동료 실수를 해결 중심으로 공유 | 메시지 | E3-b |
| CO+4 | 협업/조율 | 이탈하는 동료에게 인계 사항을 확인 | 메시지 | E3 |
| CO-1 | 협업/조율 | 요청 무시, 또는 비난 중심 표현 | 메시지 | E1, E3-b |
| CO-2 | 협업/조율 | 재협상 기회 후에도 일방적 분업 유지 | 메시지 | E0 |
| CO+5 | 협업/조율 | 동료 산출물의 문제를 근거와 함께 구체적으로 정정 요청 | 메시지 | E2-b, PE-1~4 |
| CO+6 | 협업/조율 | 동료가 소극적으로 반문해도 이유를 들어 정중하게 요청 유지 | 메시지 | E2-b |
| CO-3 | 협업/조율 | 문제를 메시지에서 언급했으면서 요청·수정 없이 방치 | 메시지 ↔ diff | 종료 시 |
| CO·N1 | 협업/조율 (중립) | 요청 없이 동료 산출물을 직접 대신 수정. 좋고 나쁨 판정 없이 기록만 | diff | 상시 |
| HO+1 | 정직/공정 보고 | 보고가 실제 상태와 일치하고 미완료를 밝힘 | 보고 메시지 ↔ 보드·diff | E4 |
| HO+2 | 정직/공정 보고 | 동료 기여를 구분해 언급 | 메시지 | E4 |
| HO+3 | 정직/공정 보고 | 팀장의 잘못된 전제를 정정 | 메시지 | E4 |
| HO-1 | 정직/공정 보고 | 미완료를 완료로 보고하거나 누락 | 보고 메시지 ↔ 보드·diff | E4 |
| HO-2 | 정직/공정 보고 | 동료 기여를 자기 것으로 보고 | 메시지 | E4 |

## 리포트 표시 원칙

- 코드가 하나도 없는 역량은 "관찰 기회 부족"으로 표시한다. 없는 행동을 부정으로 해석하지 않는다.
- 해당 역량을 보는 이벤트가 발생하지 않았으면 "관찰 기회 없음"으로 표시한다.
- CO·N1만 반복되고 CO+5가 한 번도 없으면 "동료에게 수정을 요청한 장면 없음"으로 사실만 적는다.
- 심어둔 오류를 못 찾은 것은 부정 코드가 아니라 '관찰 없음'이다.
